# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
v2.1. In short: be respectful and constructive. Harassment or discrimination of any kind isn't
tolerated.

Report unacceptable behaviour to the maintainers via a private channel (see [SECURITY.md](SECURITY.md)
for contact). Maintainers may remove comments, commits, issues, or contributors that violate this code.
